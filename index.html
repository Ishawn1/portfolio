SmartKheti: Edge AI Precision Agriculture Architecture

Problem Space: Small pomegranate farms in dryland regions of India lack cellular connectivity and cannot support cloud-based computer vision APIs. Latency, cellular data fees, and network drops render centralized cloud architectures unusable.

Sub-Millisecond On-Chip Diagnostics (ESP32-S3)

The field unit features an ESP32-S3 N16R8 running a custom, hand-crafted 3-layer Multi-Layer Perceptron (MLP) written in C++ (6 input features → 16 hidden → 8 hidden → 2 outputs). Running directly inside internal SRAM, it calculates crop water stress and inspection risk in 0.02 ms from live RS485 Modbus soil telemetry and microclimate sensors.

Android YOLO26n INT8 Vision Pipeline

The companion Flutter application hosts 4 INT8-quantized TensorFlow Lite vision models executing directly on Android hardware without internet:

  • Disease Detection: YOLO26n INT8 detects Alternaria, Fungal Spot, and Bacterial Blight in real time.
  • Pest Detection: YOLO26s INT8 covers 9 classes including aphids, red spider mites, and whiteflies.
  • Phenological Stage: 5-class growth stage classifier (bud, flower, fruit, mature).

Offline Wi-Fi Access Point Telemetry

The ESP32-S3 operates as a Wi-Fi Access Point. The Flutter app polls /data with token authentication every 4.5 seconds with a 15-second hardware watchdog and an automated 15-minute notification cooldown persisted across app restarts.

Model Quantization & Calibration Methodologies

Edge deployment demands squeezing neural networks into strict memory and thermal envelopes without degrading inference accuracy.

Post-Training Quantization (PTQ) vs QAT

For vision models like YOLO26n, standard dynamic range quantization still incurs floating point overhead during activations. By collecting representative calibration tensors across real field lighting conditions and using KL divergence calibration, we quantize both weights and activations to signed 8-bit integers (INT8). 

// INT8 Quantization Mapping
q = clamp(round(r / scale) + zero_point, -128, 127)

// Execution Benefits on Edge Silicon:
- 4x reduction in memory footprint (14.8MB -> 3.7MB)
- 4.5x speedup on mobile NPU / Hexagon DSP
- Drastic reduction in thermal throttling during continuous live scanning

Hardware Delegate Mapping

Ensuring operators (e.g., Concat, Conv2D, LeakyReLU) map directly to Android NNAPI and GPU delegates without CPU fallback kernels, which are the primary culprits behind micro-stutter in live video feeds.
